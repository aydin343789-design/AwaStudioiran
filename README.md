# AwaStudio TTS Pro - استودیو تبدیل متن به صوت هوشمند فارسی و انگلیسی

یک اپلیکیشن پیشرفته، با طراحی اختصاصی رابط کاربری موبایل (Mobile UI/UX) برای تبدیل متن به گفتار با بالاترین دقت تلفظ، تنظیمات پیشرفته لحن و سرعت، ذخیره‌سازی فایل‌های صوتی با کیفیت بالا و آماده‌سازی کامل برای ساخت فایل APK اندروید و انتشار در GitHub.

---

## 🌟 ویژگی‌های برجسته (Key Highlights)

1. **صحت و دقت بسیار بالا در تلفظ کلمات فارسی (بدون غلط)**:
   - دارای سیستم اعراب‌گذاری هوشمند خودکار (فتحه َ، کسره ِ، ضمه ُ، تشدید ّ، تنوین ً، سکون ْ).
   - رفع خطاهای کلمات هم‌نگاشت (مانند: مِهر vs مُهر، کِرم vs کَرَم، شُکر vs شِکَر).
   - تبدیل خودکار ارقام و تاریخ‌ها به حروف فارسی روان جهت خوانش بدون لغزش.
   - اصلاح خودکار نیم‌فاصله در افعال و کلمات ترکیبی.

2. **تنظیم دقیق سرعت و لحن (Pitch & Rate Controls)**:
   - تنظیم گام صدای گوینده (بم و عمیق تا زیر و جوان).
   - سرعت خوانش متغیر از ۰.۵x تا ۲.۰x با دکمه‌های پرش سریع.
   - قالب‌های آماده (Presets): گوینده رادیو و پادکست، کتاب صوتی و قصه‌گویی، گوینده خبر رسمی، آموزشی و شمرده، خلاصه‌خوانی پرانرژی.

3. **خروجی صوتی چند فرمتی و اشتراک‌گذاری سریع**:
   - ذخیره‌سازی با فرمت استاندارد بدون افت کیفیت `WAV` (16-bit PCM 44.1kHz).
   - پشتیبانی از فرمت‌های `WebM` و `MP3`.
   - اشتراک‌گذاری سریع (Web Share API) در پیام‌رسان‌ها (تلگرام، واتساپ، ایتا، روبیکا، بله).
   - آرشیو و تاریخچه فایل‌های صوتی ساخته شده در دستگاه.

4. **اجرای ۱۰۰٪ آفلاین (بدون نیاز به اینترنت)**:
   - بهره‌گیری از کتابخانه‌های وب و Web Speech API محلی دستگاه.
   - بهره‌مندی از Service Worker برای لود کامل برنامه حتی هنگام قطعی اینترنت.

5. **آماده برای ساخت خودکار APK در GitHub**:
   - دارای فایل اکشن `.github/workflows/build-apk.yml`.
   - با یک `git push` ساده در ریپازیتوری، فایل `app-debug.apk` در تب Actions گیت‌هاب تولید می‌شود.
   - دارای پیکربندی `capacitor.config.json` برای توسعه با اندروید استودیو.

## 💻 راه‌اندازی و اجرای محلی (Local Development)

```bash
# نصب وابستگی‌ها
npm install

# اجرای برنامه در حالت توسعه
npm run dev

# ساخت نسخه پروداکشن
npm run build
```
